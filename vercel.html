Vercel Deployment

SmartEdu is fully configured for seamless deployment on Vercel. The vercel.json file defines routing rules and caching headers so your smart education platform loads fast and works flawlessly in production.

Vercel Ready

vercel.json Configuration

What This Config Does

  • Serves styles.css with immutable caching
  • Serves script.js with immutable caching
  • Redirects all non-file routes to index.html (SPA)
  • Optimized for static hosting with custom headers

Quick Deploy

# Install Vercel CLI
npm i -g vercel

# Deploy to production
vercel --prod

Deployment Steps

  • 1 Ensure vercel.json is in the project root
  • 2 Run vercel for preview or vercel --prod for production
  • 3 Connect your Git repository to Vercel for auto-deploys
  • 4 Your SmartEdu platform goes live with a global CDN
